# Chocolate Sales Dataset

## Overview
This repository contains a structured chocolate sales dataset designed for data analysis, business intelligence, and machine learning practice.

## Dataset Description
The dataset includes sales records across different regions, products, and time periods. It can be used to analyze trends, revenue performance, and customer demand.

## File Structure
- `chocolate_sales(2).csv` – Main dataset file in CSV format

## Use Cases
- Exploratory Data Analysis (EDA)
- Sales trend analysis
- Revenue forecasting
- Dashboard creation
- Machine learning projects

## Format
- CSV (Comma-Separated Values)
